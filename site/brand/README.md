# Brand

The logo is an **open outline**: a house drawn with a line that never closes, with tiles inside for the activities in the model. The gap is the open part: the model is open to see, to change and to reuse.

## Files

| File | Use |
|---|---|
| `logo.svg` | The logo on light backgrounds |
| `logo-white.svg` | The logo on the brand green or other dark colours |
| `favicon.svg` | Browser tab icon. Switches colours in dark mode. |
| `favicon-32.png` | Tab icon for older browsers |
| `apple-touch-icon.png` | Phone home screen icon (180 × 180) |
| `social-card.png` | The preview image when the atlas is shared (1200 × 630) |

## Rules

- Green frame with one amber tile on light backgrounds.
- Lighter teal frame on dark backgrounds, such as the navigation bar.
- All white, with one warm tile, on the brand green.
- Never black, and never close the gap in the outline.
- Wordmark: "Open Housing" in Literata over "Operating Model" in IBM Plex Sans, or "Open Housing Operating Model" on one line in Literata.
